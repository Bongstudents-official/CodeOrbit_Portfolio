# Personal Developer Portfolio — Shubhadeep Samanta

A clean, fast, and responsive personal portfolio website built to showcase my web development skills, featured projects, and contact details as part of the **CodeOrbit Tech Web Development Virtual Internship (Batch 3)**.

## 🔗 Links

- **GitHub Repository:** [https://github.com/Bongstudents-official/CodeOrbit_Portfolio](https://github.com/Bongstudents-official/CodeOrbit_Portfolio)

## 🛠️ Technologies Used

- **HTML5:** Semantic structure (`header`, `section`, `article`, `footer`) and accessible form labels.
- **CSS3:** Custom properties (`:root` variables), Flexbox, CSS Grid, sticky navigation with backdrop blur, and mobile-first responsive media queries.
- **Vanilla JavaScript (ES6+):** Mobile hamburger menu toggle, client-side contact form validation with live status feedback, and dynamic copyright year rendering.

## ✨ Key Features

- **Responsive Navigation:** Sticky top navbar with smooth anchor scrolling and a collapsible mobile menu.
- **Hero & About Sections:** Highlights core developer focus alongside key coding metrics.
- **Categorized Skills Grid:** Organizes Frontend, Backend & Data, and Tools & Workflow skills into clean tag cards.
- **Projects Showcase:** Responsive card layout displaying project summaries, tech stack badges, and links to live demos and source code.
- **Interactive Contact Form:** Real-time input and email format validation with accessible (`aria-live`) confirmation messages.

## 📂 Project Structure

```text
├── index.html      # Main HTML document and page sections
├── styles.css      # Responsive styling, layout grids, and CSS variables
├── script.js       # Mobile menu toggle, form validation, and dynamic year
└── README.md       # Project documentation
```

## 🚀 Setup Instructions

No build tools, package managers, or external dependencies are required to run this project locally.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Bongstudents-official/CodeOrbit_Portfolio.git](https://github.com/Bongstudents-official/CodeOrbit_Portfolio.git)
   ```
2. **Navigate to the project folder:**
   ```bash
   cd CodeOrbit_Portfolio
   ```
3. **Run the project:**
   - Open `index.html` directly in any web browser, **or**
   - Launch it with a local development server (such as VS Code Live Server or `python -m http.server 8000`).
